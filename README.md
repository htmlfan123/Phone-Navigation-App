A lightweight, mobile-first navigation experience built with plain HTML, CSS, and JavaScript. Search for a place, choose a destination, and follow a live route directly in your browser.

**[Try the live app →](https://phonenav.vercel.app)**

## ✨ Features

- 📍 Live GPS tracking with high-accuracy browser geolocation
- 🔎 Location search and nearby address suggestions
- 🗺️ Interactive OpenStreetMap-powered map
- 🧭 Driving routes generated by OSRM
- 📢 Turn-by-turn text and spoken navigation
- 🚦 Remaining distance, estimated travel time, and speed display
- 🔄 Automatic route recalculation when you leave the route
- 🎯 Map recenter controls and destination pinning
- 📱 Mobile-friendly full-screen interface
- 🔒 Screen wake lock support while navigating

## 🖼️ How It Works

1. Open the app and allow location access.
2. Search for an address, landmark, or place.
3. Select a suggestion or tap the map to choose a destination.
4. Follow the route from the navigation panel.
5. Use **Recenter** to restore the live map view or **End** to stop navigation.

## 🛠️ Built With

## 🚀 Run Locally

A local web server is recommended because the browser APIs and external services may not work reliably from a `file://` URL.

```bash
# Clone the repository
git clone https://github.com/htmlfan123/Phone-Navigation-App.git
cd Phone-Navigation-App

# Start a local server
python -m http.server 8000
```

Then visit <http://localhost:8000/phonenavfinal.html>.

For geolocation and wake lock features, access the app through `localhost` or HTTPS. Real browser support and permissions can vary by device.

## 🌐 Browser Notes

- Location access is required for turn-by-turn navigation.
- Speech output depends on the voice support available in the browser and operating system.
- Screen wake lock support is not available in every browser; the app safely continues without it.
- The app connects to public map, search, and routing services, so an internet connection is required.
